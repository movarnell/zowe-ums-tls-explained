# Working on this site

This is a buildless static website. Edit index.html and app.js directly. Keep asset URLs relative so GitHub Pages project paths work.

Preserve the distinction between UMS API-server native TLS and separately documented AT-TLS backend connections. Cite primary IBM/Zowe sources for technical claims and label version-specific assumptions and illustrative ports.

Before publishing, run node --check app.js and verify affected interactions in a browser when available. GitHub Pages publishes main from the repository root.
